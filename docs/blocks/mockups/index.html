Console mockups · phase 1

Static screens for the features in docs/blocks/03-planning.md, built from the console's real tokens and shadcn base-nova components. Every state is a link, so each can be captured into Figma.

Into Figma
Open a state below, then run the html.to.design browser extension on the tab (it captures local files). Add ?theme=dark to any link for the dark version. Colours arrive as hex because Figma has no oklch; the values are generated from web/src/styles.css.
